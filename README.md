## What is dis?

this is a simple bat script to disable and enable windows 10/11 cpu mitigations since Microsoft is a pussey for not adding it on settings

## What I get from Enabling and disabling Cpu mitigation?

### Enabling gives you

- software mitigations from critical cpu vulnerabilities
- security
- but it makes the cpu slightly work hard, making it a bit slower

### Disabling gives you

- Full cpu performance
- but leaves your cpu vulnerable to Spectre v1 and v2, l1tf, srbds, tsa, retbleed and more cpu vulns
